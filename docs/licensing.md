# Licensing

## Software

CPO-STCM software is licensed under `AGPL-3.0-only`.

The AGPL includes network-use source-availability obligations. Organizations
that cannot comply must evaluate an alternative licensing arrangement with the
copyright holders before deployment.

## Dataset

CPO-LED Bench owner-provided images, annotations, splits, manifests, and derived
evidence are licensed separately under `CC-BY-4.0`. The dataset license does not
apply to source code.

The published `v2.0.1` dataset release changes citation metadata and adds a
DOI; it does not relicense or alter the v2.0.0 data payload.

## Ultralytics

Ultralytics documents AGPL-3.0 and Enterprise licensing paths. The open-source
path carries source-availability requirements for derivative work and network
deployment. Users are responsible for reviewing the current upstream terms and
obtaining an Enterprise License when appropriate.

## Third-party packages

See `THIRD_PARTY_LICENSES.md` for the direct dependency boundary. Release
artifacts must preserve upstream notices and exact dependency versions.

This document is an engineering record, not legal advice.
