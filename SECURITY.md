# Security policy

## Supported versions

Security fixes are applied to the latest stable release. Pre-release snapshots
may change without notice.

## Reporting

Do not disclose a suspected vulnerability in a public issue. Send a concise
report to `wangwanli@jcut.edu.cn` with affected versions, reproduction steps,
impact, and any proposed mitigation.

## Data handling

The base package does not require credentials and does not upload user data.
The optional Ultralytics dependency may use its own configuration and network
features; review its settings and documentation before deployment.
