# Template notes

Prepared against the official public Software Impacts Original Software
Publication template:

https://legacyfileshare.elsevier.com/promis_misc/SIMPAC_Article_Template.pdf

Template title: Software Impacts article template Version 2, July 2021.

The template requires:

- title, authors, affiliations, and emails;
- an abstract of approximately 100 words;
- at most six keywords;
- C1-C9 code metadata;
- up to three pages of body text excluding metadata, tables, figures, and
  references;
- impact overview, limitations, and enabled-publication list;
- a software reference when the repository has a DOI.

Recheck the current Guide for Authors in the live submission system immediately
before submission. The working draft is prepared locally and is not a journal
submission.
